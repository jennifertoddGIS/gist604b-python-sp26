## Project Description
This project focused on developing Python-based GIS skills using a containerized development environment in GitHub Codespaces. I worked through Jupyter notebooks to analyze tabular, vector, and raster data using pandas, GeoPandas, and Rasterio.

## Tools and Technologies
- Python
- pandas
- Geopandas
- Rasterio
- Jupyter Notebooks
- Codespaces

## What I Did
- Set up and worked in a containerized development environment using Github Codespaces
- Completed Jupyter notebooks for tabular, vector, and raster data analysis
- Used pandas to clean, filter, and analyze tabular datasets
- Used GeoPandas to read, manipulate, and analyze vector spatial data
- Used Rasterio to process raster datasets 

## How to View / Run
- Open the repository in GitHub Codespaces 
- Launch and run the Jupyter notebooks (.ipynb) to view code and outputs
